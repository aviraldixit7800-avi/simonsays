Simon Says Game 🎮

A simple and interactive Simon Says memory game built using HTML, CSS, and JavaScript.

🎯 About

The game generates a sequence of colors, and the player has to remember and repeat the sequence correctly. With every successful round, the sequence becomes longer and the difficulty increases.

✨ Features
Interactive color buttons
Random sequence generation
Level progression
User input validation
Game-over detection
Simple and responsive UI
Built without any external libraries
🛠️ Technologies Used
HTML5
CSS3
JavaScript
📁 Project Structure
├── index.html
├── style.css
├── app.js
└── README.md
▶️ How to Run
Clone or download this repository.
Open the project folder.
Open index.html in your web browser.
Start playing!

No installation or dependencies are required.

🎮 How to Play
Press the start key/button.
Watch the color sequence carefully.
Click the buttons in the same order.
If your sequence is correct, the game moves to the next level.
The sequence gets longer as you progress.
One wrong move ends the game.
